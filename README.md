## Smart Suggestions: Instant Access to Recent Files

Double-tapping the Ctrl key summons the floating search bar, which now surfaces **recently used** files by default. Users no longer need to type initial keywords to track down documents they **just handled** or access directories opened moments earlier. This automatic history display eliminates redundant queries during multi-step office workflows. Future iterations are slated to incorporate a persistent Pin function, converting frequently accessed documents into a tailored workspace directly inside the search bar.

## Preview Upgrade and Batch File Operations

Locating files among identical naming structures usually requires opening items in external software one by one. The **V7 Beta** resolves this pain point by **directly previewing** file contents inside a dedicated side pane integrated into the search results.



▲ Preview documents directly in the small window on the right

Alongside live previews, the search results interface introduces a robust **multi-select feature** designed for batch handling across different directories. Users can pick multiple results simultaneously to execute moves, copies, or deletions. To organize crowded result lists, the interface adds **sorting by size or path**, making it straightforward to filter through duplicate project files or target specific system paths without extra navigation steps.

## Performance Leap on the Rust Engine

Under the hood, the entire search architecture transitions to the **Rust tech stack**, completely rebuilding the query kernel. Official benchmarks cite a 30% reduction in memory overhead paired with a 20% acceleration in search execution.

In everyday desktop scenarios, this architectural shift eliminates input lag: **startup and search response** feel instantaneous even under heavy system load. For utility software called upon dozens or hundreds of times per workday, this latency-free execution forms the bedrock of an efficient operating environment.

The settings console has been streamlined to prevent complex configuration hunting. The overall visual style now matches modern desktop aesthetics, introducing **multiple theme colors** and a dedicated dark mode tailored for low-light work environments.
